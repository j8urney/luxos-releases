# Luxos releases

Signed, notarized builds of **Luxos** for macOS, and the update feed the app checks.

- **Download:** the latest stable build is on the [Releases](../../releases) page — open the `.dmg` and drag Luxos to Applications.
- **Updates:** Luxos checks `appcast.xml` in this repository and shows an **Update** badge when a newer build is available.
  - **Stable** builds are tagged versions (`v0.12.0`).
  - **Beta** builds are published on every push to the main branch; choose *Luxos → Update Channel → Beta* to receive them.

This repository contains only built apps; the source lives elsewhere.
